## Exact research question

Holding corpus, tokenizer, train/validation/test source split, training-token budget, decoding, and a separately reported parameter or compute budget fixed, does an **explicit** lower-layer difference \(\Delta_t^{l-1}=h_t^{l-1}-h_{t-1}^{l-1}\) routed through MIM-N and MIM-S reduce contradictions in 3–5 sentence autoregressive story continuations? The most important control receives **both** \((h_t^{l-1},h_{t-1}^{l-1})\) and learns a projection: that projection can represent subtraction exactly. A positive result against a one-state LSTM alone would be weak evidence for explicit differencing.

The rival hypothesis is that the pair projection or a simpler recurrent model learns equally useful transitions, while MIM's extra gates add optimization cost and overfit synthetic transitions. **Falsification signal:** the pair control matches or exceeds MIM on the locked, human-checked primary metric over multiple seeds, within source-pair clustered uncertainty, or MIM gains vanish on licensed natural stories. Monitor event coverage and the fraction of outputs with a concrete new event so generic text cannot score as consistent by saying nothing.

## Original MIM equation to code map

Original source: [Wang et al., CVPR 2019](https://arxiv.org/abs/1811.07490), [author repository](https://github.com/Yunbo426/MIM). The network code uses TensorFlow and convolutions over image feature maps. Our code uses PyTorch vector projections over token features; it is a **variant**.

**Paper versus author-code detail.** The paper expresses MIM-N as a difference-processing module within the MIM block. The published TensorFlow network uses a separate `MIMN` recurrent layer; at higher layers it passes the lower differential feature onward. Its first step calls a zero-input MIM-N for variable creation and passes a zero differential into the block. Our BOS convention is an explicit zero signal; the vector gates and state packaging differ from the convolutional implementation. Neither `direct` nor `cascade` should be described as an exact replication of the original video model.

The \(M\) path has two viable token decisions: (1) retain a vector zigzag memory (`mim`) and (2) remove it (`mim_no_m`) to save parameters and disentangle N/S effects. Both must be width-adjusted for parameter matching and separately profiled for compute. A third future option is an attention-like memory over token states, but it would be a new architecture requiring its own ablation. Convolutions are replaced with affine projections because a token is a vector, not a 2-D image grid; using 1-D local convolutions would create a different receptive-field hypothesis and should be tested separately if introduced.
