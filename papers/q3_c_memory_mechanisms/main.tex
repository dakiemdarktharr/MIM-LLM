\begin{abstract}
This planned study isolates the roles of the non-stationary, stationary and
additional memory paths in a vector adaptation of Memory in Memory for language
modeling. It compares ablations with a control that sees both consecutive hidden
states and can learn their difference. The study will quantify consistency,
writing quality and measured resource costs rather than infer architectural
value from parameter count alone.

\section{Question and distinct scope}
Which of MIM-N, MIM-S and the additional zigzag memory \(M\) contributes useful
continuation behavior under a small-model budget? Are observed differences due
to transition bias, capacity or extra compute? The independent contribution
must be a mechanistic or efficiency finding, not a second publication of the
Q1 study's main system ranking.

MIM originated in video prediction~\cite{mim}; nesting already exists in
Nested LSTMs~\cite{nested}. Delta-RNN~\cite{delta} uses gated recurrent updates,
and minGRU~\cite{mingru} provides an input-gated recurrent control.
Adapting these cells to token vectors does not by itself demonstrate a new
language capability.

\section{Vector mechanism and ablation definition}
Let \(u_t=h_t^{\ell-1}\), \(v_t=h_{t-1}^{\ell-1}\). The explicit MIM signal is
\(\delta_t=u_t-v_t\), followed by MIM-N and MIM-S:
\[
 D_t=\operatorname{MIMN}(\delta_t,N_{t-1}),\qquad
 T_t=\operatorname{MIMS}(D_t,C_{t-1},S_{t-1}),\qquad
 C_t=T_t+i_t\odot g_t .
\]
The outer hidden output combines \(C_t\) with the optional zigzag \(M_t\).
The first layer is the vector ST-LSTM analogue. All states have shape
\([B,d]\), and the first difference signal is zero.
This is a vector language-model variant of the original convolutional model;
it is not an exact replication of video experiments.

The information-matched control uses
\[
 \delta_t^{\rm pair}=W[u_t;v_t]+b.
\]
Setting \(W=[I,-I]\) and \(b=0\) represents subtraction exactly.
Therefore any benefit of explicit differencing concerns inductive bias or
optimization under the specified budget, not access to more input information.

\section{Experiments that discriminate explanations}
Use parameter-adjusted widths and a separate measured-time experiment. Profile
each arm on the intended context and hardware before allocating a cost budget.
Include an overwrite-depth stress test and a fixed-depth length test.
Compare named failure types, state-probe dynamics and gradient/optimization
diagnostics. Hidden-state plots are descriptive; causal claims need interventions.
A planned state reset or memory erasure intervention must preserve the input
sequence, identify the affected state and include a matched control intervention.

\section{Venue, limitations, and completion gate}
The primary candidate is \emph{Journal of Universal Computer Science}, with
\emph{Inteligencia Artificial} conditional on a fresh index/rank check.
Both have official free-author publication statements; submission format and
article type must be rechecked. Journal acceptance and UEH funding are separate.

A Q1 architecture paper would need broader natural-story replication, scale and
strong baseline evidence. This Q3 study may stand alone if it explains which
memory paths matter and why. Merge it if it contains only the Q1 ablation table.

reader judgments are reasons to repair or stop, not to repeat searches for a
favorable seed.
